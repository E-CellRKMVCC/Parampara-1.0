# Parampara 1.0 🚀

> **।। परंपरा से प्रौद्योगिकी तक ।।**  
> *From Tradition to Technology*

**Parampara 1.0** is an intra-college hackathon proudly organized by the **E-Cell RKMVCC** (Ramakrishna Mission Vivekananda Centenary College). It aims to bridge the gap between our rich cultural heritage and modern technological solutions. 

This repository contains the source code for the official landing page and registration portal of the event.

## 🎨 Features
- **Immersive Design**: A stunning dark-mode aesthetic with glassmorphism elements, beautiful Indian-style typography (Cinzel & Samarkan fonts), and engaging micro-interactions.
- **Fully Responsive**: Built with a mobile-first approach ensuring a seamless experience across all devices.
- **Interactive Timeline**: A responsive, alternating vertical timeline showcasing important event dates.
- **Problem Statements Portal**: Categorized problem statements featuring an animated accordion UI for exploring challenges.
- **Organizing Team Showcase**: A dedicated section introducing the E-Cell RKMVCC organizing committee.
- **Animated UI**: Powered by Framer Motion for buttery smooth scroll animations and layout transitions.

## 🛠️ Tech Stack
This project is built using modern web technologies:
- **[React](https://reactjs.org/)**: Frontend UI Library
- **[Vite](https://vitejs.dev/)**: Next-Generation Frontend Tooling
- **[Tailwind CSS](https://tailwindcss.com/)**: Utility-first CSS framework for rapid UI styling
- **[Framer Motion](https://www.framer.com/motion/)**: Production-ready animation library for React

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation
1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd Parampara
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running the Development Server
Start the Vite development server:
```bash
npm run dev
```
The application will be available at `http://localhost:5173`.
