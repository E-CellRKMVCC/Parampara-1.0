- **Problem Code**: `PS-ED-02`

- **Theme**: Smart Education
- **Track / Project Type**: Software Track (Web / Mobile Application)
- **Organized By**: E-Cell RKMVCC — PARAMPARA 1.0

---

## 🔍 Detailed Problem Description
In higher education institutions, students frequently struggle to form balanced, multidisciplinary teams for hackathons, research initiatives, and technical projects. Isolated developers, designers, and domain strategists often lack visibility into the broader campus talent pool. Relying on informal word-of-mouth or unorganized messaging channels results in skill mismatches, incomplete project rosters, and underutilized student potential.

---

## 🎯 Key Objectives & Expectations
1. **Comprehensive Student Skill Profile**: Verification of technical skills, GitHub/Behance/LinkedIn portfolio scoring, availability schedules, and project preferences.
2. **Algorithmic Team Formation**: Recommendation engine using clustering algorithms (e.g., Stable Matching, Constraint Satisfaction, Graph Neural Networks) to match complementary skill sets (e.g., Frontend + Backend + AI + UI/UX + Domain Expert).
3. **Hackathon / Project Host Dashboard**: Tools for event organizers to auto-assemble balanced teams or recommend ideal teammates to solo participants.
4. **Campus Talent Discovery Network**: Search, filter, and chat system for peer-to-peer collaboration requests.

---

## 🛠️ Suggested Technical Stack
- **AI/ML & Matching Algorithms**: Python (NetworkX, Scikit-Learn, SciPy optimization, OR-Tools for constraint satisfaction).
- **Backend Framework**: Node.js (Express / NestJS) / Python (FastAPI), GraphQL / REST API.
- **Frontend App**: React / Next.js, Tailwind CSS, Vite.
- **Database & Real-time Chat**: PostgreSQL, Redis, Socket.io / Firebase for real-time notifications.
