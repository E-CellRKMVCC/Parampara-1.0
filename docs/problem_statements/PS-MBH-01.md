# Problem Statement: PS-MBH-01

## 📌 Problem Overview
- **Problem Code**: `PS-MBH-01`
- **Title**: Digital Traceability & Botanical Authentication Platform for Ayurvedic Medicinal Herbs
- **Theme**: MedTech / BioTech / HealthTech
- **Track / Project Type**: Software Track (Web Application / Database Management System)
- **Organized By**: E-Cell RKMVCC — PARAMPARA 1.0

---

## 🔍 Detailed Problem Description
Adulteration and accidental misidentification of medicinal plants (e.g., substituting Bacopa monnieri with look-alike species) pose severe risks to herbal drug efficacy and consumer safety. Raw herbal supply chains in India are fragmented, making it difficult for pharmaceutical buyers to verify whether harvested plants possess the correct phytochemical composition, geographic origin, or morphological characteristics required for official Ayurvedic pharmacopoeias.

---

## 🎯 Key Objectives & Expectations
1. **AI Computer Vision Botanical Authentication**: Implement deep learning models to classify leaf/stem morphology and detect look-alike adulterants from smartphone photos.
2. **Phytochemical Certificate Verification**: Store High-Performance Thin-Layer Chromatography (HPTLC) & HPLC lab reports linked to harvest batches.
3. **Geo-Location & Batch Traceability**: Track herbal raw materials from geo-tagged wild collection / cultivation sites to processing units.
4. **Ayurvedic Pharmacopoeia Compliance Portal**: Match batch test results against official API (Ayurvedic Pharmacopoeia of India) quality standards.

---

## 🛠️ Suggested Technical Stack
- **AI/ML & Computer Vision**: PyTorch / TensorFlow (ResNet, EfficientNet, MobileNet for edge inference), OpenCV.
- **Backend & Database**: Python (FastAPI / Django), PostgreSQL, PostGIS for geo-tagged harvesting origins.
- **Frontend / PWA**: React / Vite, Progressive Web App for field collectors and lab analysts.
- **Blockchain / Audit Trail (Optional)**: Immutable log ledger for verification certificates.
